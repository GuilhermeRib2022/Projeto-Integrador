# Projeto-Integrador
- Projeto Integrador Engenharia Informática;
  
### Descrição
- Aplicação web que permite docentes publicar e organizar vídeos educativos, tutoriais, ou outros conteúdos da faculdade. Esta plataforma permite com que alunos aprendam mais facilmente e tenham o acesso mais fácil à informação que condiz com o conteúdo programático da faculdade.
  
### Linguagens usadas
- O projeto é feito em React como Frontend, Node.js como Backend e Mysql como Base de Dados.

### Configuração do Ambiente

1. Instale os arquivos do github
2. Dê "npm install" dentro do client como no server
3. Copie o arquivo `.env.example` para `.env`
4. Preencha as variáveis com os valores apropriados

- Caso queira instalar o llm: (Os modelos são pesados e poderão não funcionar num computador fraco)

1. Instale o OLllama.
2. ollama run qwen2.5:14b
3. ollama run qwen2.5vl:7b
